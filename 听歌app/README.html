听歌 · 生活内容管理

本机浏览器中的个人内容管理 App。无需账号、后端或云数据库；收藏、保存路径、偏好设置和内容缓存保存在浏览器 IndexedDB。

打开听歌 App 运行浏览器测试

运行

可直接在桌面浏览器打开 index.html。如果浏览器限制本地文件访问或外部公开接口请求，请在项目目录启动本机静态服务器：

python -m http.server 8000

然后访问 http://localhost:8000。项目无需安装前端依赖或构建。

测试

在同一浏览器打开 tests/test-runner.html。页面会显示每项测试的通过/失败结果，覆盖路由、数据存储、来源数据校验、开放授权媒体筛选与搜索、刷新失败缓存、路径管理、历史年份解析、主题样式及备份格式校验。

外观主题

在“数据与设置”中可选择深蓝科技、浅色或深色主题。主题应用于首页和其他功能页面，并保存在当前浏览器中；首次使用默认采用深蓝科技主题。

公开来源与边界

  • 今日热门歌曲：QQ 音乐热歌榜为首选来源；请求失败时自动回退到网易云音乐热歌榜。
  • 热门视频：抖音公开热搜榜展示话题关键词并可跳转到抖音搜索页；热搜词条不是视频内容。
  • 历史流行单曲：按年份读取 Wikipedia 上的 Billboard 年终 Hot 100 页面；只显示页面可访问且表格通过校验的数据。
  • 网页内播放：歌曲页和视频页提供 Wikimedia Commons 开放授权媒体搜索，可播放受支持的音频/视频文件，并显示可获得的许可证信息及来源署名链接。

QQ 音乐/网易云榜单条目是榜单信息而非可直接播放的音频流；抖音热搜是关键词而非视频文件。要在网页中播放媒体，请使用歌曲页或视频页中的 Wikimedia Commons 搜索。播放取决于网络、浏览器格式支持及文件可用性。

外部网站可能限流、变更接口或不可访问。更新失败时保留最近一次成功缓存并显示状态；没有缓存时明确提示无法获取，不生成模拟榜单。来源字段、封面、年份和排名以公开页面实际内容为准。

本机数据与备份

保存路径只保存用户输入的文字，不扫描或读取本机文件。备份采用带版本标识的 JSON 格式；恢复前会提示确认，并整体替换本机数据。
